# Fra JSON til API

## Hva jeg har gjort

I dette arbeidet har jeg jobbet med JSON, JavaScript og API-er.

Jeg har laget og testet forskjellige JavaScript-lister. Jeg lærte hvordan man kan hente ut forskjellige elementer fra en liste ved å bruke plasseringen til elementet.

Jeg har blant annet jobbet med en liste med spill og en liste med favorittmat. Jeg testet:

- Det første elementet i en liste
- Det siste elementet i en liste
- Hvor mange elementer listen har
- Hvordan man legger til et nytt element
- Hvordan man fjerner et element
- Hvordan man kan skrive ut alle elementene med en løkke

Jeg har også jobbet med JSON-filer med artister. Der brukte jeg en JSON-fil med informasjon om artister, for eksempel navn, sjanger, land, album og populære sanger. Jeg brukte JavaScript for å hente informasjonen fra JSON-filen og vise den på nettsiden.

Jeg har også undersøkt JSON-filer med vitser. Jeg sammenlignet `justJokes.json` og `jokes.json` og undersøkte hvordan de var bygget opp.

Til slutt laget jeg en nettside med:

- `index.html`
- `script.js`
- `style.css`

På nettsiden hentet jeg informasjon fra JSON-filene og viste den på en ryddig måte.

## Hva jeg har lært

Jeg har lært mer om hvordan JSON fungerer og hvordan informasjon kan lagres i JSON-filer.

Jeg har lært at en liste starter på plass `0`, og at man derfor bruker for eksempel `liste[0]` for å finne det første elementet.

Jeg har også lært at `.length` kan brukes for å finne hvor mange elementer det er i en liste.

Jeg har lært hvordan jeg kan bruke `.push()` for å legge til noe i en liste og `.splice()` for å fjerne noe.

Jeg har lært hvordan en `for`-løkke kan brukes for å gå gjennom alle elementene i en liste.

Jeg har også lært hvordan JavaScript kan hente informasjon fra JSON og vise informasjonen på en nettside.

## Det jeg synes var nytt

Det som var nytt for meg var å jobbe med JSON-filer og å hente informasjon fra dem med JavaScript. Jeg lærte også at JSON kan være bygget opp på forskjellige måter. Noen JSON-filer kan ha en enkel struktur, mens andre kan inneholde objekter, lister og flere typer informasjon.

## Oppsummering

Gjennom oppgavene har jeg fått bedre forståelse for hvordan JavaScript, JSON og nettsider kan brukes sammen. Jeg har lært hvordan man kan lagre informasjon i JSON og hente den fram med JavaScript for å vise den på en nettside.
