💡 Hva er et API?

Et API (Application Programming Interface) er en måte for programmer å be andre programmer om data. Jeg sender en forespørsel til en adresse (en URL), og serveren svarer med data – vanligvis i JSON-format.

Hva er forskjellen mellom JSON og et API?

Lokal JSON-fil API
Hvor? Ligger på min egen datamaskin Ligger på en annen datamaskin (server)
Endres? Jeg må endre filen manuelt Serveren oppdaterer seg selv
Trenger internett? Nei Ja
Eksempel artist.json jokeapi.dev

Kort sagt: JSON er formatet på dataene, mens et API er veien jeg får tak i dataene på.
